# Astronaut 3D Model Directory

Place your `Astronaut.glb` file directly in this folder:
```
frontend/public/models/astronaut/Astronaut.glb
```

### Fallback Mechanism:
If `Astronaut.glb` is not present, `AstronautAvatar.jsx` will automatically render a high-fidelity procedural EVA space suit avatar with reflective gold visor, articulated joints, and thruster plumes to ensure a crash-free experience.
