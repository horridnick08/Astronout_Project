# Spaceship / Corridor 3D Model Directory

Place your spaceship, corridor, or orbital habitat GLB file here:
```
frontend/public/models/spaceship/Spaceship.glb
```

### Fallback Mechanism:
If `Spaceship.glb` is not present, `SpaceshipEnvironment.jsx` automatically renders a procedural aerospace sci-fi corridor / observation module complete with structural bulkheads, neon floor light paths, server conduits, and a deep space observation bay.
